# Verilog Basic Gates

This repository contains basic digital logic gate implementations using Verilog HDL.

## Implemented Gates
- AND Gate
- OR Gate
- NOT Gate
- XOR Gate
- NAND Gate
- NOR Gate

## Tools Used
- Verilog HDL
- Xilinx Vivado

## Learning Outcome
Understanding the implementation of fundamental digital logic gates in Verilog.
